# 平均分：分物入組與除式（小二課堂遊戲）

學生把物件平均分入指定組數，填寫「每組有／餘下」和單位，再寫橫式和直式。這是另一個課堂遊戲，與「乘和除的關係」「除法的認識」分開，請不要覆蓋那些專案。

公開網址：https://wkyee-class.github.io/p2-division-equal-share/

## 怎樣用

- 學生與老師用同一個網站。首頁有「學生」和「老師」兩個按鈕。
- 老師建立或重開課堂後，可投影「課堂入場」畫面：用 iPad 相機掃 QR code，再揀自己的學號即可加入。QR 指向公開學生網址，並帶上課堂編號參數 `c`，例如 `https://wkyee-class.github.io/p2-division-equal-share/?c=` 加上四位編號。QR 在網頁內本地產生，不依賴外站圖片。若 QR 未能產生，畫面仍會放大顯示四位課堂編號及完整公開網址。遲到的同學可請老師再按「顯示入場畫面」。
- 若學生打開沒有 `c` 參數的原網址，流程是：選「學生」→ 揀學號 → 輸入四位課堂編號，或選「單機練習／自己溫習」。
- 老師：登入後建立或重開課堂，把入場畫面投影給學生。控制台可看誰在線、誰已提交、做到第幾題，亦可點開作品、廣播討論、使用「講解示範」或「投影示範」、控制下一題、開新一輪和匯出資料。老師入口也可開啟：https://wkyee-class.github.io/p2-division-equal-share/teacher.html

課堂模式按「提交」後，學生畫面不會顯示對錯或正確算式。單機練習保留「檢查答案」。有餘數的題目必須寫出餘數；兩位數被除數的直式要把商對齊個位。填「每組有／餘下」時必須選對物件單位。
