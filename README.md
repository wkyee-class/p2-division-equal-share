# 平均分：分物入組與除式（小二課堂遊戲）

學生把物件平均分入指定組數，填寫「每組有／餘下」和單位，再寫橫式和直式。這是另一個課堂遊戲，與「乘和除的關係」「除法的認識」分開，請不要覆蓋那些專案。

公開網址：https://wkyee-class.github.io/p2-division-equal-share/

- 學生：主頁 → 學生 → 點學號 1–40 → 輸入四位課堂編號，或選單機練習
- 老師：主頁 → 老師，或 https://wkyee-class.github.io/p2-division-equal-share/teacher.html

課堂模式按「提交」後，學生畫面不會顯示對錯或正確算式。單機練習保留「檢查答案」。有餘數的題目必須寫出餘數；兩位數被除數的直式要把商對齊個位。填「每組有／餘下」時必須選對物件單位。
